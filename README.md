An intelligent web application designed to help high school students master Cambridge IGCSE and secondary exam past papers using automated question parsing and step-by-step AI explanation flows.

---

## ✨ Features

- 📝 **Interactive Past-Paper Solver:** Upload or paste exam questions for instant, step-by-step guidance.
- 💡 **Conceptual Explanations:** Get clear, syllabus-aligned breakdowns of difficult Physics, Chemistry, CS, and Math topics.
- 🎯 **Practice Quiz Generator:** Generate target practice questions based on your weak areas.

---

## 🛠️ Tech Stack

- **Frontend / UI:** Streamlit
- **Backend Core:** Python 3.10+
- **AI Engine:** Google Gemini API / OpenAI API
